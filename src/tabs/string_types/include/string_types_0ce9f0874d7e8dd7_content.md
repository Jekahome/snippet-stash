

Предполагаемое использование для SmartString - это тип ключа для B-дерева (например, std::collections::BTreeMap) или любой операции с массивом, где локальность кэша имеет решающее значение.

В целом, это хороший тип данных для уменьшения выделения памяти в куче и повышения локальности строковых данных. 
Если вы используете SmartString в качестве замены для String, вы почти наверняка увидите небольшой прирост производительности, а также небольшое снижение использования памяти.
