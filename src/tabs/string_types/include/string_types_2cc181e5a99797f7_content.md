

Чтобы быть уверенным, что char может содержать любой символ, он должен быть 4 байта. 

Так как 2 байта (u16) наибольшее число, которое вы можете составить, это 65 535, что значительно меньше количества букв во всех языках мира (одних только китайских иероглифов больше!). 

Но у u32 (4 байта) предлагает более чем достаточно места, позволяя разместить до 4 294 967 295 букв, поэтому char это u32
Но всегда использовать 4 байта нужно только для char типа. 

Строки (String) отличаются и не всегда используют 4 байта на один символ. 
Когда символ является частью строки String или &str (не типа char), строка кодируется так, **чтобы использовать наименьшее количество памяти, необходимое для каждого символа**.
