

По умолчанию обобщённые функции будут работать только с типами чей размер известен во время компиляции `Sized`.
<pre><code class="language-rust">
// Поэтому компилятор из этого:
   fn generic<T>(t: T) {...}
// делает это:
   fn generic<T: Sized>(t: T) {...}
</code></pre>

Но мы может сами снять это ограничение на размер.
Явно обозначить что `T` с неизвестным размером во время компиляции
<pre><code class="language-rust">
fn generic<T: ?Sized>(t: &T) {...}
</code></pre>
