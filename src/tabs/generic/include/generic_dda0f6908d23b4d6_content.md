

Если проблему можно решить с помощью static dispatch (статический механизм), вам лучше сделать это, чтобы избежать штрафов производительности определения типа во время выполнения.
 Наиболее распространенным примером, когда вы не можете использовать  static dispatch и должны использовать dynamic dispatch, являются гетерогенные коллекции (где каждый элемент потенциально отличается от конкретного типа, но каждый реализует MyTrait)
