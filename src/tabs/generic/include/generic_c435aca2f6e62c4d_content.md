

По умолчанию обобщённые функции будут работать только с типами чей размер известен во время компиляции.
Поэтому компилятор из этого:
<pre><code class="language-rust">
   fn generic<T>(t: T) {...}
делает это:
   fn generic<T: Sized>(t: T) {...}
</code></pre>

Но мы может сами снять это ограничение на размер
Явно обозначить что `T` будет иметь или не будет иметь известный размер во время компиляции
<pre><code class="language-rust">
   fn generic<T: ?Sized>(t: &T) {...}
</code></pre>
