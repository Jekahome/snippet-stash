

#### ORM

**Асинхронные ORM и библиотеки**

- [diesel-async](https://docs.rs/diesel-async): Асинхронная обёртка для Diesel, предоставляющая async-версии основных методов.
- [sea-orm](https://docs.rs/sea-orm): Асинхронный и динамичный ORM, ориентированный на простоту использования и поддержку нескольких баз данных.
- [sea-query](https://docs.rs/sea-query): Конструктор SQL-запросов, поддерживающий MySQL, PostgreSQL и SQLite.
- [ormx](https://docs.rs/ormx): Лёгкие derive-макросы для добавления ORM-подобных возможностей в sqlx.
- [rustorm](https://docs.rs/rustorm): SQL-центрированный ORM с акцентом на удобство преобразования типов базы данных в соответствующие типы Rust.

**Дополнительные ресурсы**

- [SeaORM: Дизайн и парадигма программирования](https://www.sea-ql.org/SeaORM/docs/internal-design/diesel#programming-paradigm): Сравнение парадигм программирования между SeaORM и Diesel.
