

#### Migrations


Ресурсы по миграциям баз данных в Rust

**Общие ресурсы**
- [Are We Web Yet? — Database Tooling](https://www.arewewebyet.org/topics/database#tooling): Обзор инструментов для работы с базами данных в экосистеме Rust.

**Миграции для Diesel**
- [diesel_migrations](https://docs.rs/diesel_migrations): Управление схемой базы данных с помощью миграций в Diesel.
- [diesel_cli](https://docs.rs/diesel_cli): Командная строка для управления миграциями и схемой базы данных в Diesel.

**Миграции для SQLx**
- [sqlx-cli](https://docs.rs/sqlx-cli): Утилита командной строки для управления миграциями и базами данных с использованием SQLx.
- [SQLx CLI — Create and Run Migrations](https://github.com/launchbadge/sqlx/tree/main/sqlx-cli#create-and-run-migrations): Официальная документация по созданию и запуску миграций с использованием SQLx CLI.

**Другие инструменты для миграций**
- [refinery](https://docs.rs/refinery): Мощный инструмент для миграций в Rust, поддерживающий SQL-миграции.
- [migrant](https://docs.rs/migrant): Лёгкий инструмент для миграций, поддерживающий различные базы данных.
- [barrel](https://docs.rs/barrel): Утилита для создания схемы базы данных с использованием Rust.
