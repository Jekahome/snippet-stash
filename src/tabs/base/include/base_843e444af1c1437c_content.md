

Компилятор должен проверить поток выполнения программы (flow-sensitive) на допустимость выполнения условий.
Цикл while содержит какие-то требования exp, следовательно, при не соблюдении этих требований, поток выполнения пойдет иным образом но в коде не предусмотренно для этого варианта, тут приходит на помощь loop

```rust
fn test()->i32{
/*
    while exp {
        return 1i32;
    }
*/
    
    loop{
        return 1i32;
    }
}
fn main(){}
```
