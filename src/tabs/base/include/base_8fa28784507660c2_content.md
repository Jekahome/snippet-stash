

`{}` — выражение. Его цель - превратить любое выражение в оператор. 

`1 + { let x = 2; x * 2 }`

Блок состоит из инструкций (statement), завершённых.

Значение блока — значение хвостового выражения.

```rust
fn main(){
    let i: i32 = { 1 };

    let i: () = { 1; };
}
```

Точки с запятой имеют значение!
