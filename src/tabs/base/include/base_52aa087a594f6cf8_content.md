


Встроенные характеристики для бинарных операторов


| Категория                  | Имя характеристики      | Выражение | Эквивалентное выражение |
|----------------------------|-------------------------|-----------|--------------------------|
| **Арифметические операторы** | std::ops::Add           | x + y     | x.add(y)             |
|                            | std::ops::Sub           | x - y     | x.sub(y)                |
|                            | std::ops::Mul           | x * y     | x.mul(y)                |
|                            | std::ops::Div           | x / y     | x.div(y)                |
|                            | std::ops::Rem           | x % y     | x.rem(y)                |
| **Поразрядные операторы**    | std::ops::BitAnd        | x & y     | x.bitand(y)          |
|                            | std::ops::BitOr         | x \| y    | x.bitor(y)              |
|                            | std::ops::BitXor        | x ^ y     | x.bitxor(y)             |
|                            | std::ops::Shl           | x << y    | x.shl(y)                |
|                            | std::ops::Shr           | x >> y    | x.shr(y)                |
