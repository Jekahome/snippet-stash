

Применение атрибута к функции `f` позволяет коду внутри `f` получить подсказку о Location «самом верхнем» отслеживаемом вызове, который привел к `f`вызову. 
В точке наблюдения реализация ведет себя так, как будто она поднимается по стеку от `f` кадра, чтобы найти ближайший кадр функции без атрибутов `outer`, и возвращает Location отслеживаемый вызов в `outer`
<pre><code class="language-rust">
#[track_caller]
fn f() {
    println!("{}", std::panic::Location::caller());
}

fn f2() {
    f();
}
 
fn main(){
  f2();
}
</code></pre>
