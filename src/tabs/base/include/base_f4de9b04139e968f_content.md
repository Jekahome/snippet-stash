

Типаж Drop имеет только один метод: drop, который вызывается автоматически, когда объект выходит из области видимости. 
Основное применение типажа Drop заключается в том, чтобы освободить ресурсы находящиеся в куче, которыми владеет экземпляр реализации 

Box, Vec, String, File, и Process - это некоторые примеры типов, которые реализуют типаж Drop для освобождения ресурсов.
