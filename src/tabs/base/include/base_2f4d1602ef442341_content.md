

**PartialEq Частичное равенство** для типов, которые не имеют полного отношения эквивалентности ( `==` ). 
Например, в числах с плавающей запятой NaN != NaN, поэтому типы с плавающей запятой реализуются, `PartialEq` но не `Eq`

**PartialOrd и Ord Упорядочивающие traits** позволяют сравнивать  ( `<, >, <=, >=`) два элемента одного типа, возвращая Less, Greater или Equal
