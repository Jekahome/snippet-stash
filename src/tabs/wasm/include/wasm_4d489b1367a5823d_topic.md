

**Client-side / WASM**

* **[cargo-web](https://github.com/koute/cargo-web)** — подкоманда Cargo для компиляции и работы с клиентской частью Web (WASM).
* **[leptos](https://crates.io/crates/leptos)** — full-stack, изоморфный веб-фреймворк с тонкой реактивностью для декларативного построения UI.
* **[sauron](https://github.com/ivanceras/sauron)** — клиентский веб-фреймворк, который строго следует архитектуре Elm.
* **[seed](https://seed-rs.org/)** — фреймворк для создания веб-приложений на Rust.
* **[stdweb](https://github.com/koute/stdweb)** — стандартная библиотека для клиентской разработки на WebAssembly.
* **[tinyweb](https://github.com/tejainece/tinyweb)** — минимальный Rust веб-фреймворк для WASM, \~800 строк кода.
* **[yew](https://yew.rs/)** — фреймворк для написания клиентских веб-приложений с компонентным подходом, похожим на React.
