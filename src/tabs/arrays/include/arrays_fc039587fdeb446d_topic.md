

pub fn **sort_by_cached_key`<K, F>`(&mut self, f: F)**

Сортирует срез с помощью функции извлечения ключа.
Во время сортировки ключевая функция вызывается только один раз для каждого элемента.
Для простых ключевых функций (например, функций, которые имеют доступ к свойствам или основные операции), 
**sort_by_key** скорее всего, это будет быстрее.
