

Он устанавливает переменные среды из .env файла который начинает искать из папки запуска , 
если таковые имеются, и сбрасывает данные с фактическими переменными среды, предоставляемыми операционной системой.

**dotenv_codegen** предоставляет макрос **dotenv!**, который ведет себя идентично env!, но сначала пытается загрузить .env файл во время компиляции.
