

**by_ref**() - Нужен для того, чтобы использовать [адаптеры](https://jekahome.github.io/snippet-stash/tabs/iterator/index.html#%D0%9C%D0%B5%D1%82%D0%BE%D0%B4%D1%8B-iterator) (**chain, take, bytes, итераторы** и т.д.) без потери владения объектом.

даёт временную ссылку, чтобы работать с методом как с итератором или адаптером, а после можно продолжить использовать оригинальный объект.
