


```
(i integer -1 - +1) знаковые  
(u 0-1) беззнаковые
(i32) фиксированного размера
(isize, usize) переменного размера
(f32, f64) числа с плавающей точкой 
(i32, u32) целые числа

Числовые литералы Пример
Десятичный        98_222
Шестнадцатеричный 0xff
Восьмеричный      0o77
Бинарный          0b1111_0000
Байтовый (только u8) b'A'
```
