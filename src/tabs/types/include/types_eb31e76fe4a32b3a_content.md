

Абстрактный шаблон. Объяснить компилятору, что данный тип должен предоставлять определённую функциональность
Типаж, содержащий лишь сигнатуру метода или дефолтную реализацию, а затем реализуем (impl) для нужной `struct/enum`

Все методы trait должны быть реализованы impl методами struct/enum и лишних не должно быть  
Trait по умолчанию ограничен (trait bound) трейтом `&Sized` т.е. возможно не имеет размер
