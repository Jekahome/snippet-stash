

Основной мотивирующий пример для пустого типа - недостижимость на уровне типа.
Например, предположим, что API должен возвращать Result в целом, но конкретный случай на самом деле безошибочен. 
На самом деле можно сообщить об этом на уровне типа, вернув `Result<T, Void>`. 
Потребители API могут уверенно развернуть такой Результат, зная, что статически невозможно, чтобы это значение было равно Err, поскольку для этого потребуется предоставить значение типа `Void`
