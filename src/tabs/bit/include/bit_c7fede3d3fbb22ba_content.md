


<pre><code class="language-rust">
#[repr(C, packed)]
struct Packed {
    a: u16, // 2 байта
    b: u32, // 4 байта
}
</code></pre>

* `#[repr(C, packed)]` убирает выравнивание (padding), которое обычно добавляется компилятором.
* Полезно для работы с бинарными протоколами или аппаратурой, где структура должна точно соответствовать формату.
* Минус: доступ к полям может быть медленнее на некоторых архитектурах из-за выравнивания.
