

Работа с бинарными протоколами

* **[`byteorder`](https://crates.io/crates/byteorder)** — удобное чтение/запись чисел из потоков в big/little endian.
* **[`bytes`](https://crates.io/crates/bytes)** — эффективный буфер для сетевого кода.
* crate [**serde**](https://crates.io/crates/serde) + crate [**bincode**](https://crates.io/crates/bincode) — сериализация структур в бинарный формат.
