

Однако, следует использовать Rc с умом , он не будет освобождать память (утечка памяти) при зациклить ссылки. 
Rust не может предотвратить утечки памяти во время компиляции (хотя и затрудняет их создание). 
Если по-прежнему требуется цикл ссылок, вы должны использовать Weak интеллектуальный указатель («слабую ссылку») в сочетании с Rc. Weak позволяет прервать цикл ссылок, поскольку может ссылаться на значение, которое уже было отброшено ( None в таком случае возвращается ).
