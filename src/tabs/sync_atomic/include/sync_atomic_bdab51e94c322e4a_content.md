

Этот порядок обеспечивает только атомарность операций (т.е., операция выполняется как единое целое, без прерываний). Он не гарантирует никакой дополнительной синхронизации между потоками.
Подходит для случаев, когда вам не нужно заботиться о том, как значения соотносятся между потоками, кроме обеспечения атомарности самой операции.

Пример: Подсчёт количества событий в многопоточном приложении, где важен только корректный счёт, но не порядок этих событий.
<pre><code class="language-rust">
use std::sync::atomic::{AtomicU64, Ordering};
fn main(){
    let atomic_value = AtomicU64::new(0);
    atomic_value.store(1, Ordering::Relaxed);
    let value = atomic_value.load(Ordering::Relaxed);
}
</code></pre>
