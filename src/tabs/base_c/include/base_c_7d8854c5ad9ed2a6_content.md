

При сравнении чисел с плавающей запятой вы должны использо­вать только операции `<` и `>`. 

Это объясняется тем, что из-за ошибок округления два чис­ла могут оказаться неравными, хотя логически они должны быть равны.

```c

#include <stdio.h>
#include <stdlib.h> // EXIT_SUCCESS

int main(void) { 
 
    printf("%d",1.12345678f  == 1.12345678f);//1
    printf("%d",1.123456789f == 1.123456785f);//1 -  может сранивать 8 знаков, а 9 знаков уже не может

    return EXIT_SUCCESS;
}
```
