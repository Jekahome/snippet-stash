

Функция с переменным количеством параметров


Вы должны выполнить следующие действия.
1. Подготовить прототип функции, в котором применяется троеточие.
2. Создать в определении функции переменную типа va_list.
3. Использовать макрос va_start для инициализации этой переменной списком аргументов.
4. Применить макрос va_arg для доступа к списку аргументов.
5. Использовать макрос va_end для очистки.
