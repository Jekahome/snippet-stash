

Тестовые функции должны быть свободными, мономорфными функциями, не принимающими аргументов, 
а возвращаемый тип должен реализовывать трейт **std::process::Termination**

* macro **assert!**
* macro **assert_eq!**
* macro  **assert_ne!**
* macro [**debug_assert!**](https://doc.rust-lang.org/std/macro.debug_assert.html)

crate [**spectral**](https://crates.io/crates/spectral) - различные assert
