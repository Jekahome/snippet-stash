

Для библиотеки с общедоступным API, опубликованным на crates.io, я избегаю модульных тестов. 
Вместо этого я использую один интеграционный тест, называемый ( integration test ):it

```
✅ Для не больших crates:   
tests/
  it.rs

✅ Или для больших crates:  
tests/
  it/
    main.rs
    foo.rs
    bar.rs
```

Интеграционные тесты используют библиотеку как внешний контейнер. 
Это вынуждает использовать тот же общедоступный API, который используют потребители, что приводит к улучшению обратной связи при проектировании.
