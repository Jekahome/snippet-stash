

**CLI**-тестирование

* crate [**assert_cmd**](https://crates.io/crates/assert_cmd) - Простая инициализация и утверждения команд.
* crate [**assert_fs**](https://crates.io/crates/assert_fs) - настройки файловой системы и утверждения для тестирования
* crate [predicates](https://crates.io/crates/predicates) - составные функции предикатов первого порядка.
* crate [rexpect](https://crates.io/crates/rexpect) - для интерактивного тестирования CLI.
