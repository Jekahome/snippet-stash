

Дополнительные crate для работы с документацией:

crate [**cargo-deadlinks**](https://crates.io/crates/cargo-deadlinks) - проверяет документацию на наличие битых ссылок

crate [**grammarly**](https://crates.io/crates/grammarly) - проверка грамматики английского языка в документации

crate [**cargo-readme**](https://crates.io/crates/cargo-readme) - создает файл README из кода документации проекта

crate [**doc-comment**](https://crates.io/crates/doc-comment) - макросы для условной документации
